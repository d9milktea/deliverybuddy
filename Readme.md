# 取單率計算工具

主要用途給熊貓外送員，當您取單率低於 87% 時，預估需要連續完成的訂單數量。這個工具會根據使用者輸入的完成訂單件數與目前區間取單率，動態計算並顯示一個表格，呈現從當前狀態到達 87% 目標所需的數值。

## 功能
- **取單率計算**：根據使用者輸入的完成單數和目前取單率計算總派單數與進一步需要完成的訂單數。

## 如何執行
1. 輸入上線歷程看到的過往紀錄完成訂單件數。
2. 輸入上線歷程看到的區間取單率。

# 外送罐頭包

提供外送員在不同情境下快速回應客戶的常用罐頭句子範例。

## 功能
- **通知客戶已到達**：
  - 您好，我已到達取餐地點，正在等待餐點準備完成。
  - 您好，我已到達送餐地點，請問方便下來取餐嗎？
- **延遲通知**：
  - 抱歉，因交通狀況，送餐時間可能會稍有延遲，感謝您的耐心等待。
  - 抱歉，餐點準備時間較長，可能會稍晚送達，敬請見諒。
- **完成訂單**：
  - 您好，餐點已送達，祝您用餐愉快！
  - 感謝您的訂單，期待再次為您服務！

## 如何執行
1. 根據情境選擇適合的罐頭句子。
2. 複製並貼上到與客戶的對話中。
